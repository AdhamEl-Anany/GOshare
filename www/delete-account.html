🗑️ 1. Delete Specific Data Without Deleting Your Account

GOshare empowers users to selectively delete individual files and data items at any time without closing or deleting their account:

How to Delete Specific Files:

  1. Log in to your account at GOshare Dashboard or via the Android Mobile App.
  2. Navigate to the "My Files" section.
  3. Locate the file you wish to delete and click the "Delete" (🗑️) icon.
  4. Confirm deletion. The file binary will be instantly purged from Firebase Cloud Storage and its metadata removed from Firestore.

⚠️ 2. Request Complete Account & Data Erasure

When you request account deletion, GOshare permanently purges all data associated with your user account across all backend systems.

What Data is Permanently Deleted?

  • User Profile & Credentials: Email address, display name, user ID, and authentication tokens in Firebase Authentication.
  • Uploaded Files: All documents, photos, videos, and archives stored in Firebase Cloud Storage.
  • Database Records: All file metadata, custom short URLs, download counts, and access permissions stored in Firestore.
  • Local Storage Cache: All cached session data on your local device.

🕒 4. Data Retention & Policy Clarifications

Instant Purge: Upon confirmation of deletion, user profile information, authentication credentials, and uploaded files are deleted immediately from active storage.

Temporary Retention: Server access logs (such as IP addresses and rate-limit logs used strictly for DDoS protection and fraud prevention) may be retained for up to 30 days in backup logs before automated permanent purging. We do not retain user files or personal information after account deletion.

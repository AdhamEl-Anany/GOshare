**GOshare** is a state-of-the-art, high-performance, responsive cloud file sharing platform & Android application inspired by MediaFire with an emerald & diamond dark glassmorphism design. Powered by **Google Firebase** (Auth, Firestore, Storage), **Chart.js Analytics**, and **Capacitor 8 Native Bridge** for seamless web & mobile file management.

---

## 🚀 Recent Feature Updates (v1.2.0)

- 📂 **Full Folder Upload Support (Bulk Upload)**: Upload entire folder hierarchies with `webkitdirectory` or select multiple files at once under a single session.
- 🎁 **Referral Bonus Program (+2 GB per Friend)**: Share your unique referral link (`auth.html?ref=UID`). Every new user registration awards **+2 GB extra free storage** to both you and your friend with live real-time counters.
- 📊 **Interactive Data Analytics Suite**: Built-in **Chart.js** dynamic charts in the Dashboard and Admin Panel visualizing user activity trends, file transfers, storage consumption, and growth metrics.
- ✦ **Golden Shimmer Premium Aesthetics**: Gold shimmer animated username text (`.premium-name`), golden storage indicator bars, custom SVG social icon buttons, and clean glassmorphism UI.
- 🔑 **Self-Service Password Reset & Email Recovery**: Password recovery flow connected to Firebase Auth with custom sender name (`GOshare`).
- 🏢 **Lifetime & Enterprise Tiers**: Support for permanent lifetime subscriptions, customizable plan badges, and auto-hidden upgrade buttons for premium users.

## 🌟 Key Features

- 🔒 **Firebase Authentication & OAuth**: Full user signup/signin, Google & GitHub OAuth popups, session persistence, and secure profile management.
- 📂 **Recursive Folder Uploads**: Drag-and-drop or select folders; GOshare processes directory structures and uploads files concurrently with live progress indicators.
- 🎬 **In-Browser Media Players & Previews**: Instant streaming & previews for HD Videos (`.mp4, .webm, .mov`), Audio tracks (`.mp3, .wav, .ogg`), Documents (`.pdf, .txt`), and Images (`.png, .jpg, .webp, .svg`).
- 🔐 **Password-Protected File Links**: Set custom security passwords for shared files so only authorized users with the passcode can view or download.
- ⏳ **Auto-Expiring Links**: Set custom expiration limits (e.g. 24 hours, 7 days) after which shared file links automatically expire.
- 🔗 **Cryptographic Short Links**: Powered by `crypto.getRandomValues()` to generate secure 10-character IDs (`file.html?s=aB3xZ9K1mP`).
- 💳 **PayPal Live & Dynamic EGP InstaPay Gateways**: Integrated PayPal Live SDK and real-time live currency exchange rate converter for InstaPay transfers in Egyptian Pounds.
- 📊 **Comprehensive Admin Panel**: Management suite for reviewing premium upgrade requests, user growth analytics, system statistics, and storage utilization.

## 🛠️ Tech Stack

- **Web Frontend**: HTML5, Vanilla CSS3 (Custom Glassmorphism, CSS Variables, Shimmer Keyframes), JavaScript (ES6+)
- **Mobile Engine**: Capacitor 8 (Cross-Platform Android Native Bridge)
- **Data Visualization**: Chart.js (CDN-integrated responsive charts)
- **Backend & Database**: Google Firebase (Authentication, Cloud Firestore, Storage)
- **CI/CD & Cloud Build**: GitHub Actions Workflows (`build-android.yml`)
- **Payment Gateways**: PayPal Live SDK & Live Currency Exchange Rate API (USD to EGP)
- **Deployment**: GitHub Pages / Firebase Hosting
